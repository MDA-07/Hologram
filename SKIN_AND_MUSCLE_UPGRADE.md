# Skin opacity and muscle anatomy upgrade

- Added a dedicated OUTER SKIN opacity slider (0–100%). It affects only parts assigned to the `skin` system; the existing HOLOGRAM slider continues to control non-skin layers.
- Expanded the procedural superficial muscle layer with named pectoral, deltoid, biceps, triceps, forearm, abdominal, oblique, serratus, latissimus, gluteal, quadriceps, hamstring, calf and tibialis groups.
- The added forms are improved stylized procedural approximations. They are not medically validated, individually segmented anatomical meshes. For high-fidelity anatomy, replace/augment them with properly licensed and medically reviewed GLB/GLTF assets.

Run `flutter analyze` and `flutter run --release` to validate on a Flutter SDK installation.
