# Muscle colour update

- Rectus abdominis segments are rendered brick red (`#B55239`).
- Other modeled skeletal muscles (striated muscle) are rendered cream (`#FFE8C2`).
- Selecting a muscle still applies the existing yellow selection highlight.
- The muscle layer opacity slider continues to affect both colours.

Terminology: rectus abdominis is itself a skeletal (striated) muscle. This colour scheme uses brick red to distinguish that named muscle from the rest of the striated skeletal-muscle layer; it does not imply that rectus abdominis is a different tissue type.

These are visual categories for the current procedural model, not histology-level tissue models.
